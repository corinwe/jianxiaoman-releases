## 件小满 · 采集器 v0.1.3（安卓）

**三步就能用（不用登录、不用找人要令牌）：**

1. 下载下面的 `jianxiaoman-collector-v0.1.3.apk`，允许「未知来源」后安装（覆盖安装即可，数据不丢）
2. 打开 App → 点 **① 一键激活** → 屏幕上出现 **6 位配对码** → 再点 **② 开启通知使用权**
3. 打开微信「**件小满**」小程序 → 底部「**连接手机**」→ 输入那个 6 位配对码 → 完成

之后：到件通知自动记账；7 天无理由到期前会提醒你；验证码类短信云端直接丢弃（不留存）。
